사용 방법 (3분 요약)
  1. 오늘 탭의 "오늘 할 일"대로 하면 됩니다. 숫자 타일을 누르면 해당 탭으로 갑니다.
  2. 원고 탭에서 원고를 고르고 [자동 입력]을 누르면 크롬에 글·이미지·영상이 들어가고 발행 창에 주제·예약 시각(다음 빈 날 20:30)까지 채워집니다. 네이버의 [발행] 버튼만 직접 누르고, 돌아와서 [발행 완료 처리].
  3. 이웃 탭은 받은 신청 수락과 서로이웃 신청, 댓글 탭은 이웃 새 글에 댓글. 하루 10개면 충분합니다.
  4. 자동 작업(원고 생성 06시·통계 08:10·색인 확인 하루 4번·받은 이웃 수락 10·20시·순위 월요일)은 터미널에서 npm run schedule 한 번 등록하면 맥이 켜져 있는 동안 돕니다.

점검

1원고 고르기

클로드가 쓴 원고가 여기 쌓입니다. 자동 작업을 등록했다면 매일 06:00에 설정한 편수만큼 추가되고, 지금 바로 필요하면 아래에서 만들 수 있습니다.

불러오는 중…

2확인하고 에디터에 넣기

왼쪽에서 원고를 고르면 미리보기와 네이버 검색 노출 검사 결과가 나옵니다. 검사를 통과한 원고만 자동 입력할 수 있습니다.

👈 왼쪽 목록에서 원고를 선택하세요

4이웃 늘리기

기초연금·노인일자리·노후준비 같은 우리 주제로 글을 쓰는 활동 블로거를 찾아 점수순으로 보여줍니다. 이웃이 되면 그 사람의 피드에 우리 글이 노출됩니다. 새 글을 발행한 날에 하는 것이 수락률이 좋습니다.

받은 서로이웃 신청 확인 중…

상대가 먼저 보낸 신청입니다. 수락이 늦으면 취소되니 바로 받고, 수락 직후 상대의 최신 글에 글 내용을 짚은 환영 댓글을 하나 답니다(체인 신호). 매일 10시·20시에 자동으로도 돌아갑니다.

반자동 (권장) — 후보마다 [열기] → 열린 창에서 [확인]만 클릭

서로이웃 선택과 인사 메시지는 자동으로 채워져 있습니다. 확인을 눌렀으면 [신청함]으로 기록하세요. 관심 없는 블로그는 [건너뛰기].

완전 자동 — 클릭까지 프로그램이 대신

여러 명에게 12~40초 간격으로 자동 신청합니다. 네이버가 제한·보안문자를 띄우면 즉시 스스로 멈춥니다. 하루 상한은 설정 탭에서 바꿀 수 있습니다.

[후보 새로 찾기]를 눌러 시작하세요

5이웃 새 글에 댓글

문안 제안 진행 중…

네이버는 이웃 수가 아니라 읽고·댓글 달고·다시 오는 관계(체인)를 봅니다. 이웃이 오늘 올린 글을 모아 보여주고, 글 내용을 짚은 댓글 문안을 클로드가 제안합니다. 우리 주제와 겹치는 글이 위로 옵니다. 문안은 고쳐 써도 됩니다. 하루 10~20개면 충분하고, 네이버가 보안문자를 띄우면 그날은 멈춥니다.

[새 글 불러오기]를 눌러 시작하세요

실행 설정

네이버 로그인자동 입력용 크롬에 한 번 로그인. "로그인 상태 유지" 체크. 로그인이 풀리면 여기서 다시
하루 생성 편수자동 작업(06시)이 만드는 원고 수. 한 편에 3~8분, 클로드 사용량이 듭니다
하루 발행 상한검사기의 1일 발행 건수 제한. 0 = 제한 없음
예약 발행 시각쉼표로 여러 개 적으면 하루 발행 수가 됩니다. 예: 08:30,20:30 → 하루 2편. 자동 입력 때 발행 창에 "예약"을 켜고 그날 비어 있는 슬롯부터 채우며, 예약 대신 "현재"로 바로 발행해도 블로그 글 목록과 대조해 그날 발행 수에 넣습니다. 비우면 예약 안 함. 10분 단위
