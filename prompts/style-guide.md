### 원칙
- 한 사람의 사정으로 시작한다. 누가 왜 알아봤는지가 첫 문단에 있다. ("직장을 그만두고 오래 쉬신 분들이 ○○를 알아보다가 창구에서 그냥 돌아오는 일이 있습니다.")
- 한 문장은 한 줄에 다 쓴다. 두세 문장이 이어져 한 문단이 되고, 화제가 바뀌면 빈 줄.
- 종결은 "습니다/입니다/~다"가 기본. "~더라고요", "~는데요"는 글 전체에 두세 번만.
- 숫자는 독자가 자기 상황에 대입할 것만. 표 데이터는 본문에 나열하지 말고 카드 이미지 한 장에 넣는다.
- 설명하다가 자기 판단을 한 번씩 섞는다. ("이 부분이 제일 헷갈렸습니다") 단 꾸며낸 체험은 금지.
- 소제목은 문장으로. ("12월에 신청하면 요율이 한 칸 올라갑니다")

### 하지 말 것 (검사기가 본다)
- 줄표(—) 1개 초과, 괄호 10개 초과, 이모지 소제목
- "핵심은 ~입니다" / "즉," / "~하는 것이 중요합니다" / "~를 추천합니다" / "흔한 실수 세 가지" / "내일 바로 할 체크리스트" / "결론부터 말씀드리면" / "알아보겠습니다"
- "> 핵심 요약 / 한눈에 보기" 인용구 블록으로 시작 — 인용구는 사람 말이나 공식 문장 인용에만
- 문장 중간 줄바꿈(시처럼 끊는 것)
- 억지 토속어: 예순다섯·일흔·칠십 퍼센트·값어치 — 65세, 70%, 가치 라고 쓴다
- 구어 어미(더라고요·는데요·거든요·잖아요·죠) 글 전체 6회 초과, "저는"으로 시작하는 줄 2회 초과, "할 수 있습니다" 4회 초과
- 숫자 표현(원·%·세·만) 15개 초과 → 카드 이미지로 옮긴다
