# 네이버 블로그 자동발행기 (로컬 설치형)

```bash
git clone https://github.com/GrowthHong/naver-blog-autopublisher.git
cd naver-blog-autopublisher && zsh install.sh && npm start
```

내 맥에서 돌아가는 네이버 블로그 운영 도구입니다. 서버에 아무것도 보내지 않고, 내 크롬과 내 클로드로만 동작합니다.

- **원고 생성**: 클로드가 주제를 고르고 공식 출처를 확인해 원고 1편 + 카드 이미지 4~5장을 만듭니다
- **검사**: 네이버 노출 규칙(유사문서·기승전링크·글자수·이미지)과 문체 금지 목록을 자동 검사
- **자동 입력**: 크롬이 열리고 제목·본문·서식·이미지·슬라이드 영상이 네이버 에디터에 들어갑니다. 발행 창에 주제와 예약 시각까지 채워 주며, **[발행] 버튼만 직접** 누릅니다
- **이웃·댓글**: 받은 서로이웃 신청 자동 수락 + 환영 댓글, 서로이웃 신청 후보 발굴·자동 신청, 이웃 새 글에 댓글 문안 제안·등록
- **통계·순위·색인**: 블로그 통계(유입 검색어·조회수), 검색 순위, 색인 누락 확인을 자동 수집해 보고서로

## 글 유형
설정 탭에서 블로그에 맞는 유형을 고릅니다. 유형마다 "무엇을 사실로 쓸 수 있는지"와 글 구조가 달라집니다.

| 유형 | 맞는 블로그 | 사실 규칙 |
|---|---|---|
| 정보·제도 안내 | 정부 혜택, 법·세금, 건강 정보 | 공식 출처에서 확인한 숫자만. 개인 경험 금지 |
| 리뷰·후기 | 제품, 맛집, 장소, 서비스 | **참고 메모에 적은 경험만** 재료. 스펙·가격은 공식 페이지 확인 |
| 노하우·방법 | 설정법, 요리, 수리·관리 | 절차는 공식 안내로 확인, 메모가 있으면 우선 |
| 뉴스·트렌드 | 신제품, 제도 변경, 업계 소식 | 보도자료·공식 발표만. 추측은 추측이라고 |
| 일상·생각 | 에세이, 기록 | **참고 메모만** 재료, 웹 검색 안 함 |

리뷰·일상 유형은 원고 탭의 **참고 메모**(겪은 일, 수치, 사진에 찍힌 것, 좋았던 점·아쉬운 점)가 있어야 생성되고, 자동 생성(06시)은 돌지 않습니다. 클로드가 경험을 지어내지 못하게 하기 위한 장치입니다. 유형별 규칙은 `prompts/post-types.json`에서 고칠 수 있습니다.

## 필요한 것
- macOS, [Node.js](https://nodejs.org) LTS, 구글 크롬
- [클로드 코드 CLI](https://docs.claude.com/ko/docs/claude-code) (`npm install -g @anthropic-ai/claude-code` → 터미널에서 `claude` 실행해 로그인). 원고 생성에만 필요하고, 한 편에 클로드 사용량이 꽤 듭니다
- (선택) ffmpeg — 슬라이드 영상 (`brew install ffmpeg`)
- (선택) 네이버 검색광고 API 키 — 키워드 검색량으로 주제를 거릅니다

## 설치와 실행
```bash
zsh install.sh
npm start
```
브라우저에서 http://localhost:5071 → **설정 탭**에 블로그 아이디·이름·주제 설명을 적고 저장 → [네이버 로그인 창 열기]에서 로그인("로그인 상태 유지" 체크) → 원고 탭 [새 원고 생성].

자동 작업(매일 06시 원고 생성, 08:10 통계, 색인 확인, 받은 이웃 수락, 월요일 순위 측정) 등록:
```bash
npm run schedule
```
맥이 켜져 있어야 돌아갑니다. 06시 정시 실행을 원하면 `sudo pmset repeat wakeorpoweron MTWRFSU 05:58:00`.

## 데이터 폴더
`~/.blog-autopublisher/` (환경변수 `BAP_HOME`으로 변경 가능)
- `blogs.json`, `config.json` — 설정
- `blogs/<key>/drafts/` — 원고 큐, `images/`, `published/`(발행 완료 보관)
- `chrome-profiles/<key>/` — 네이버 로그인 세션 (삭제하면 다시 로그인)
- `state/` — 댓글·수락·통계·순위·색인 기록, `reports/` — 보고서(md), `logs/`
- `searchad.json`, `oauth-token` — 선택 키 (권한 600)

## 꼭 알아둘 것
- **발행은 사람이 누릅니다.** 네이버는 자동 발행·자동 댓글·자동 이웃을 어뷰징으로 봅니다. 이 도구는 발행 버튼을 대신 누르지 않고, 이웃·댓글 자동화는 하루 상한과 무작위 간격, 보안문자 감지 시 즉시 중단이 들어 있습니다. 그래도 **본인 계정에 대한 책임은 본인에게** 있습니다. 하루 서로이웃 10~20건, 댓글 10개 안팎을 권합니다.
- 원고는 반드시 읽고 발행하세요. 금액·날짜는 공식 출처를 확인하도록 프롬프트가 짜여 있지만, 틀린 숫자가 그대로 나가면 블로그 신뢰가 깎입니다.
- 네이버 화면 구조가 바뀌면 자동 입력이 멈출 수 있습니다. 그때는 [원고 텍스트 복사]로 직접 붙여넣으세요.
